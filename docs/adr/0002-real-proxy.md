# ADR-0002 · 적층 정책은 REAL-proxy로 비교하고, 가정은 β 민감도로 따로 본다

- 상태: 채택
- 관련 코드: `stacklens/stack/sim.py`, `scripts/run_stack.py`, `tests/test_stack_sim.py`

## 맥락
HBM 적층에서 문제가 되는 것은 **테스트를 통과했지만 실제로는 불량인 다이**(잠재불량, test escape)다.
공개 데이터에는 잠재불량의 비율도 위치도 없다.

처음 설계는 잠재불량 확률을 `p = e·(r/r̄)^β` 로 두는 것이었다(r = 위험 모델 점수).
하지만 이렇게 하면 **LGBM 점수로 정답을 만들고 LGBM이 그 정답을 맞히는** 순환이 생긴다.
GDBN 규칙과 LGBM을 이 방식으로 비교하면 LGBM이 이기는 것이 당연하다.

## 결정
두 실험을 분리한다.

**A. REAL-proxy (정책 비교용)**
실제 test 웨이퍼의 **진짜 불량 다이 일부를 "통과한 척하는" 잠재불량으로 섞는다.**
잠재불량의 위치가 실제 불량의 공간 분포를 그대로 따르므로 정답이 어떤 모델의 점수에서 나오지 않는다.
각 다이의 점수는 교차 마스킹으로 자기 결과를 보지 않고 계산된 값이다(ADR-0001).
이것은 "잠재불량은 검출된 불량과 같은 공간 분포를 따른다"는 GDBN의 전제를 그대로 가정한 것이다.

**B. β 민감도 (가정의 경계용)**
그 전제가 얼마나 강한지(β)를 바꿔 가며 이득이 언제 사라지는지 본다. 정책 비교에는 쓰지 않는다.

**보정**: A의 이득과 같은 이득을 내는 β를 B의 격자에서 역으로 찾는다 → β ≈ 1.4~1.9.
실제 불량의 공간 집중도가 "위험에 비례(β=1)"보다 강하다는 뜻이다.

## 시뮬레이터 자체의 검증
- 무작위 조립의 기대 스택 수율 = 닫힌식 (E[1−p])^N (오차 1% 이내)
- 기댓값 계산 = Bernoulli로 실제 불량을 뽑아 본 Monte Carlo 400회 평균 (오차 1% 이내)
- β=0이면 선별은 절대 이득이 없다 (위험 점수가 잠재불량과 무관하므로)
- 위험 매칭 조립 > 무작위 조립 (Π(1−p)의 볼록성)
- 단수가 높을수록 최적 선별 비율이 줄지 않는다
- 대규모 실험용 빠른 스윕 = 느린 원래 함수 (상대오차 1e-9)

## 알려진 한계
REAL-proxy에서 이웃 특징은 섞인 잠재불량을 '불량'으로 봤다. 실제라면 양품처럼 보였을 것이다.
잠재불량이 통과 다이의 0.2~2%라 영향은 작지만 결과를 약간 낙관적으로 만든다.
완전히 제거하려면 잠재불량으로 뽑힌 다이를 관측 맵에서 양품으로 바꿔 특징을 다시 계산해야 한다 — 다음 과제.
