# ADR-0005 · 에이전트 프레임워크를 쓰지 않는다

- 상태: 채택

## 맥락
LLM이 하는 일은 "사실 목록을 받아 구조화된 리포트 하나를 쓰는 것" 한 단계다. 도구 호출·분기·반복이 없다.

## 결정
LangGraph 같은 에이전트 프레임워크 없이 OpenAI Responses API의 structured output(`responses.parse` + Pydantic) 한 번 호출로 끝낸다.
결정은 규칙 엔진(ADR-0003), 수치는 코드(ADR-0004)가 맡으므로 LLM 단계에 상태 기계가 필요 없다.

## 이유
- 한 단계짜리 호출에 그래프를 씌우면 테스트해야 할 것만 늘어난다
- 재현성: 같은 입력 → 같은 규칙 판정. LLM 출력의 흔들림은 "사람 검토" 표시로만 드러난다
- 모델 교체가 문자열 하나다 — 실제로 3개 모델을 같은 코드로 비교했다

## 되돌릴 조건
LLM이 도구를 골라 부르는 단계(예: 판정이 애매한 웨이퍼만 추가 데이터를 조회)가 생기면 그때 그래프를 도입한다.
